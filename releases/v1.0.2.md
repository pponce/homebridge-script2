# Script2 1.0.2

# ⚠️ **BREAKING CHANGE — BACK UP YOUR CONFIGURATION BEFORE UPDATING.**

**For users upgrading from versions before 1.0.0: legacy Script2 accessory mode and old platform configuration formats are no longer supported. Review and save a copy of your current Homebridge config.json before installing, then follow the [migration guide](https://github.com/pponce/homebridge-script2/blob/master/MIGRATION.md). Legacy configurations will no longer run.**

**Already using 1.0.0, 1.0.1, or 1.0.0-beta.1? No configuration changes or additional migration are required for this update.**

## Dependency maintenance

- Include Dependabot PR [#123](https://github.com/pponce/homebridge-script2/pull/123), updating fast-uri from 3.0.1 to 3.1.7 in the development dependency lockfile.
- fast-uri is used by Ajv for configuration-schema validation during development and release checks. Version 3.1.7 includes upstream security fixes. It is not a runtime dependency of normal Homebridge installations.
- Retain the 1.0.1 configuration-schema fix, schema regression tests, and reorganized README.

Plugin runtime behavior, runtime dependencies, configuration keys, and accessory identities are unchanged from 1.0.1. This patch records the merged dependency maintenance in the release history.

## Update

Select **1.0.2** / **latest** in Homebridge UI and restart the instance or child bridge running Script2.

Requires Node.js **22.13+ within Node 22, or Node 24**, and Homebridge **1.8+ within version 1, or version 2**. Homebridge verification remains subject to team approval.
