# Script2 1.0.4

**Users on version 1.0.x can update normally. No configuration changes or migration are required. This also applies to 1.0.0-beta.1.**

## ⚠️ Upgrading from a version before 1.0.0

**Only these older versions require migration. Back up your Homebridge config.json before updating, then follow the [migration guide](https://github.com/pponce/homebridge-script2/blob/master/MIGRATION.md).** Legacy Script2 accessory mode and old platform configuration formats are no longer supported.

## Successful commands with stderr

- ON/OFF and stateless trigger commands that exit `0` now succeed even when they write stderr. This also applies to ON/OFF scripts that create or delete a state file, and addresses the failure mechanism suspected in [issue #125](https://github.com/pponce/homebridge-script2/issues/125).
- Nonzero action exits, timeouts, termination, and other execution errors still return failures to HomeKit.
- Preserve the state-script policy from [issue #29](https://github.com/pponce/homebridge-script2/issues/29): by default, log ordinary nonzero exits and use usable stdout; with `fail_on_state_exit_code` enabled, return a state-read error to HomeKit. This option applies only to state scripts.

## Stderr diagnostics

- Normal logs show a warning when ON, OFF, trigger, or state commands write nonblank stderr.
- Enable Homebridge debug logging to see stderr text, limited to 4,096 characters with control characters escaped.
- Raw command text and stdout remain omitted. Debug stderr may contain credentials or other sensitive script output; remove secrets before sharing logs.

## Update

Select **1.0.4** / **latest** in Homebridge UI and restart the instance or child bridge running Script2.
