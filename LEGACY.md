# Legacy formats were removed in 1.0

**Back up your current config.json before updating. Legacy Script2 accessory mode and old platform list formats no longer run.**

See [MIGRATION.md](MIGRATION.md) for the supported format, before/after examples, removed aliases, identity guidance, and rollback. Historical support is documented in the [0.4.6 source](https://github.com/pponce/homebridge-script2/blob/v0.4.6/LEGACY.md).
