# Script2 1.0.8

**Users on version 1.0.x can update normally. No configuration changes or migration are required. This also applies to 1.0.0-beta.1.**

## ⚠️ Upgrading from a version before 1.0.0

**Only these older versions require migration. Back up your Homebridge config.json before updating, then follow the [migration guide](https://github.com/pponce/homebridge-script2/blob/master/MIGRATION.md).** Legacy Script2 accessory mode and old platform configuration formats are no longer supported.

## Visible checkbox states

- Fix the **Enable debug logging** checkbox appearing as a blank pill with no visible change when clicked. The shared form renderer incorrectly applied text-field styling, which hid the native checkmark when Homebridge loaded its Bootstrap styles.
- Render a square checkbox beside its clickable label with a clear checked/unchecked appearance in light and dark themes.
- Apply the same correction to polling and other checkbox settings. Existing saved values are preserved.
- Extend browser checks to include Bootstrap's appearance reset and compare checked versus unchecked images, as well as label clicks, keyboard activation, and saved settings.

The debug behavior added in 1.0.7 is unchanged: enable both Script2's checkbox and Homebridge/child bridge debug mode (`-D`), then save and restart the instance or child bridge running Script2. Normal informational messages, warnings, and errors remain visible.

## Update

Select **1.0.8** / **latest** in Homebridge UI, restart the instance or child bridge running Script2, and reopen plugin settings.
