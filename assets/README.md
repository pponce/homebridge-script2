# Script2 icon

- `homebridge-script2-icon.png`: 100 × 100 PNG for the optional Homebridge verification request icon.
- `homebridge-script2-icon-512.png`: 512 × 512 PNG for README/UI use.

The three images shown during design were successive drafts, not three required installation assets. Only the final solid-violet design is used here. The beta publisher also attaches both PNG sizes to the GitHub prerelease for direct download.

Created with the built-in image generator on September 10, 2026. Prompt: “Original simple bold graphic: a white house outline integrated with a terminal window and a clear >_ command prompt, on a deep violet square tile with one small warm amber status accent. Centered, strong silhouette, generous padding, no tiny details, no text or brand logos, no official certification badge. Recognizable at 100 × 100 pixels.” Final refinement: fill the entire background, including all corners, with solid violet; no checkerboard or transparency. The generated original was resized for packaging without changing the design. This icon does not indicate Homebridge approval.
