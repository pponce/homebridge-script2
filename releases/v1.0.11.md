# Script2 1.0.11

**Users on version 1.0.x can update normally. No configuration changes or migration are required. This also applies to 1.0.0-beta.1.**

## ⚠️ Upgrading from a version before 1.0.0

**Only these older versions require migration. Back up your Homebridge config.json before updating, then follow the [migration guide](https://github.com/pponce/homebridge-script2/blob/master/MIGRATION.md).** Legacy Script2 accessory mode and old platform configuration formats are no longer supported.

## Node.js 26 support

- Declare support for Node.js 26, including 26.13.0, alongside Node.js 22.13+ and 24.
- Resolve the Node.js compatibility warning reported in [#129](https://github.com/pponce/homebridge-script2/issues/129).
- Test Node.js 22, 24, and 26 with Homebridge 1 and 2 in CI, including the installed package, file watcher, and custom UI.
- Support Node.js 26 in the stable npm publisher and publish the archive attached to the checked GitHub release.

No plugin runtime or configuration changes are required.

## Update

After this version is published to npm, select **1.0.11** / **latest** in Homebridge UI and restart the instance or child bridge running Script2.
