# Script2 1.0.7

**Users on version 1.0.x can update normally. No configuration migration is required. This also applies to 1.0.0-beta.1.**

**Debug logging now defaults to off in Script2.** If you already use Homebridge debug mode (`-D`), enable the new **Enable debug logging** checkbox in Script2 settings to continue seeing Script2 troubleshooting details.

## ⚠️ Upgrading from a version before 1.0.0

**Only these older versions require migration. Back up your Homebridge config.json before updating, then follow the [migration guide](https://github.com/pponce/homebridge-script2/blob/master/MIGRATION.md).** Legacy Script2 accessory mode and old platform configuration formats are no longer supported.

## Control Script2 debug logging

- Add **Enable debug logging** below **Platform name** in plugin settings. It applies to all Script2 switches and defaults to unchecked.
- Require both the Script2 checkbox and Homebridge/child bridge debug mode (`-D`) for debug messages. You can leave `-D` enabled and control Script2's debug output from plugin settings.
- Keep normal informational messages, warnings, and errors visible. Homebridge's own debug output remains controlled by `-D`.
- Save and restart the instance or child bridge running Script2 after changing this setting. JSON users can set `"debug": true` on the `Script2Platform` block.

## Clearer state-command diagnostics

- Replace the misleading `state command returned output` message with an exit-code and output-presence summary, such as `state command finished (exit code: 2; state output: empty)`.
- Identify timeouts and terminated commands explicitly, without treating missing exit codes as success.
- Explain that abnormal execution discards partial state output, without incorrectly claiming that the nonzero-exit setting is enabled.
- Update stderr warnings to explain both debug settings needed to see the diagnostic text.

Command success/failure rules, state matching, accessory identities, and the configurable nonzero state-exit policy are unchanged. Raw commands and stdout remain omitted from diagnostics.

## Update

Select **1.0.7** / **latest** in Homebridge UI and restart the instance or child bridge running Script2.
